# Portfolio — Ardhiansyah

Galeri portofolio 3D (Three.js/WebGL) ala Nági: aula bundar berdinding krem, lantai kayu,
oculus langit, tiga pintu lengkung — masing-masing berisi lukisan yang bisa diklik untuk
masuk ke "dunia" proyek.

## Proyek

- **Siaprak** — aplikasi Android native (Kotlin) untuk administrasi desa.
- **Gemfund** — aplikasi mobile lintas platform (Flutter/Dart) untuk dana bersama.
- **Rolling Libur** — web satu halaman untuk 14 peserta MagangHub di PT Ethes Teknologi
  Makmur ([live](https://rolling-libur.vercel.app)).

## Jalankan

```bash
npm install
npm run dev
```

## Deploy

```bash
vercel --prod
```

Data proyek tinggal di `src/lib/projects.ts` dan juga disajikan lewat `GET /api/projects`.
